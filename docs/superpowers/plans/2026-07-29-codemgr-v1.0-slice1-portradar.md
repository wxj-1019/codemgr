# CodeMgr v1.0 切片一 — Electron 外壳 + 端口雷达 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭起 Electron 应用外壳 + IPC 调度层，把 v0.1 已验证的 `netScan` 接到首屏"端口雷达"面板，端到端可跑——证明 Electron↔native 集成路径走通，并交付第一个对用户有价值的差异化功能。

**Architecture:** Electron 主进程通过 `require()` 加载 `codemgr-native`（已用 cmake-js 为 Electron 重编译），用 `setInterval` 调度 `netScan()`，经 `contextBridge` 暴露的封装 API（`ipcRenderer.invoke` ↔ `ipcMain.handle`）推给渲染进程。渲染进程用 React + Tailwind + Zustand 渲染端口雷达表格。本切片**只做端口雷达一个面板**，进程/性能面板是后续独立计划。

**Tech Stack:** Electron 43.2.0 / React 18 + TypeScript / Tailwind CSS 3 / Zustand 4 / Vite 5（构建渲染进程）/ cmake-js（为 Electron 重编译 native addon）

**Spec reference:** `docs/superpowers/specs/2026-07-29-codemgr-design.md` §2 架构、§3.1 端口雷达、§5 IPC 调度
**v0.1 产出（依赖）:** `E:\A_Project\codemgr\codemgr-native` 导出 `netScan(): NetConnection[]`、`killProcess(pid): boolean`、`killByName(name): number`

**切片完成判据：**
1. `pnpm dev` 启动一个 Electron 窗口，首屏显示端口雷达
2. 表格列出所有监听端口（TCP LISTENING + UDP），含进程名、PID、端口、协议
3. 常用 dev 端口（3000/5173/8080/3306/27017 等）自动打标签
4. 点某行的"结束进程"能 kill 对应进程（带二次确认）
5. 数据每 3 秒自动刷新
6. 关闭窗口后进程不残留（app 退出干净）

**文件职责边界：**
- `electron/*` 只跑在主进程/preload，绝不 import 渲染层；`src/*` 只跑在渲染进程，绝不直接 `require('codemgr-native')`——只能通过 `lib/ipc.ts`（即 preload 暴露的 API）访问。这是 Electron 安全红线。
- `portLabels.ts` 是纯函数（端口→标签），独立可测，不碰 IPC。
- `usePortRadar` hook 只管"轮询 + 写 store"，不渲染；`PortRadar`/`PortTable` 只管渲染，不直接调 IPC。单向数据流。

**与 v0.1 的关系：** 不改 `codemgr-native` 的 C++ 代码，只改它的构建目标（为 Electron 重编译）。新增的 `app` 包是渲染层 + Electron 主进程。

```ts
// IPC 通道名常量（避免 main/preload/renderer 三处拼写不一致）
export const IPC = {
  FETCH_CONNECTIONS: 'net:fetchConnections',
  KILL_PROCESS: 'proc:killProcess',
  KILL_BY_NAME: 'proc:killByName',
} as const;

// 与 codemgr-native 的 NetConnection 一致（重新声明，避免渲染层直接依赖 native 包）
export interface NetConnection {
  protocol: 'tcp' | 'udp';
  localAddr: string;
  localPort: number;
  remoteAddr: string;
  remotePort: number;
  state: string;
  pid: number;
  processName: string;
}

// preload 暴露给 window 的 API 形状
export interface ExposedApi {
  fetchConnections(): Promise<NetConnection[]>;
  killProcess(pid: number): Promise<boolean>;
  killByName(name: string): Promise<number>;
}
```

- [ ] **Step 3: 写 preload.ts（contextBridge 暴露封装 API）**

Create `E:\A_Project\codemgr\app\electron\preload.ts`:
```ts
import { contextBridge, ipcRenderer } from 'electron';
import { IPC, type ExposedApi } from './ipc-types';

// 安全红线：只暴露封装后的方法，绝不暴露 ipcRenderer 本身
const api: ExposedApi = {
  fetchConnections: () => ipcRenderer.invoke(IPC.FETCH_CONNECTIONS),
  killProcess: (pid: number) => ipcRenderer.invoke(IPC.KILL_PROCESS, pid),
  killByName: (name: string) => ipcRenderer.invoke(IPC.KILL_BY_NAME, name),
};

contextBridge.exposeInMainWorld('codemgr', api);
```

```ts
import { useEffect, useRef } from 'react';
import { ipc } from '../lib/ipc';
import { usePortRadarStore } from '../store/portRadarStore';

const POLL_MS = 3000;  // 端口雷达刷新间隔（spec §5.1）

// 挂载后每 3s 拉一次连接列表写入 store。组件卸载时清定时器。
export function usePortRadar() {
  const setConnections = usePortRadarStore((s) => s.setConnections);
  const setLoading = usePortRadarStore((s) => s.setLoading);
  const setError = usePortRadarStore((s) => s.setError);
  const stoppedRef = useRef(false);

  useEffect(() => {
    stoppedRef.current = false;

    async function poll() {
      setLoading(true);
      try {
        const conns = await ipc.fetchConnections();
        if (!stoppedRef.current) setConnections(conns);
      } catch (e) {
        if (!stoppedRef.current) setError(String(e));
      } finally {
        if (!stoppedRef.current) setLoading(false);
      }
    }

    poll();  // 立即跑一次
    const timer = setInterval(poll, POLL_MS);
    return () => {
      stoppedRef.current = true;
      clearInterval(timer);
    };
  }, [setConnections, setLoading, setError]);
}
```

      </header>

          connections={connections}
